## Описание

Приложение для добавления и просмотра задач.

Используются Python, Flask, HTML, JavaScript и Nginx.

## API

- GET /apihealth — проверка состояния сервера.
- GET /api/tasks — получение списка задач.
- POST /api/tasks — добавление задачи.

## Запуск приложения

1. Установить Python 3 и python3-venv.
2. Создать виртуальное окружение:

   python3 -m venv venv

3. Активировать окружение:

   source venv/bin/activate

4. Установить зависимости:

   pip install -r requirements.txt

5. Запустить сервер:

   python app.py

Приложение работает на 127.0.0.1:5000.

Для доступа через браузер необходимо настроить Nginx:
- / — HTML-страница из папки site;
- /api/ — перенаправление на Flask;
- /apihealth — проверка состояния Flask.

В выполненной работе Nginx использует порт 8080.

## Особенности

Задачи хранятся в оперативной памяти и сбрасываются после перезапуска приложения.
